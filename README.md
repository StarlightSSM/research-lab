# 🔬 My Little Lab — 대학원생을 위한 나만의 작은 실험실

관심 연구 분야를 설정해 두면 **매일 정해진 시간에 논문·뉴스·이슈·데이터를 모아 한 화면에 정리**하고,
업로드한 논문 PDF는 **AI가 읽고 분석 리포트 PDF**로 만들어 주는 개인 연구 대시보드입니다.
모든 기능을 **무료**로 쓸 수 있습니다.

## 시작하기

1. `start_lab.bat` 더블클릭 (처음 한 번은 패키지 설치 때문에 1~2분 걸려요)
2. 브라우저에서 http://localhost:5050 이 열리면 우측 위 **⚙ 설정**에서 관심 주제/키워드를 확인하고 수정
3. **지금 수집**을 누르면 첫 브리핑이 만들어집니다

### 매일 자동 수집
- 서버가 켜져 있으면 설정한 시각(기본 08:00)에 자동으로 수집해요. PC를 늦게 켜도 그날 한 번은 실행해요.
- 서버를 켜 두지 않아도 매일 수집되게 하려면 PowerShell에서 아래 명령을 실행하세요.
  ```powershell
  .\setup_schedule.ps1                      # 매일 자동 수집 등록
  .\setup_schedule.ps1 -StartServerAtLogon  # + 로그인 때 대시보드 서버도 자동 실행
  .\setup_schedule.ps1 -Remove              # 해제
  ```

## 화면 구성

| 영역 | 내용 |
|---|---|
| 오늘의 브리핑 | AI가 새로 수집된 항목을 읽고 주제별 흐름, 오늘 꼭 볼 것 3개, 연구 아이디어를 정리 |
| KPI | 오늘 새로 들어온 논문/뉴스/이슈/데이터 수, 분석한 논문 수, 스크랩 수 |
| 피드 | 탭(논문/뉴스/이슈/데이터·코드/★스크랩) + 주제 필터 + 검색 + 기간. ☆ 스크랩, 논문은 **AI 분석** 버튼으로 바로 분석 |
| 논문 연구실 | PDF를 끌어다 놓으면 분석 → 화면에서 보기 + PDF 리포트 저장 |
| 주제 레이더 | 최근 7일 주제별 수집량 (클릭하면 필터) |

## 수집 소스 (모두 무료, API 키 불필요)

| 구분 | 소스 | 비고 |
|---|---|---|
| 논문 | arXiv | CS·통계·경제 프리프린트, PDF 바로 분석 가능 |
| 논문 | OpenAlex | 경영·마케팅·IS 저널 포함 2억+ 논문, 초록·피인용수 |
| 뉴스 | Google 뉴스 RSS (한국어/영어) | 한국어 키워드는 국내 뉴스, 영어 키워드는 해외 뉴스 |
| 이슈 | GeekNews, Hacker News | 국내외 IT·AI 커뮤니티 화제 |
| 데이터·코드 | GitHub, HuggingFace Datasets | 최근 만들어진 인기 저장소 / 실습용 데이터셋 |

새 소스를 추가하려면 `lab/collectors.py`에 함수 하나를 만들고 `SOURCES`에 등록하면 됩니다.

## 논문 분석 리포트에 들어가는 내용

기본 정보(피인용수 포함) · 한 줄 요약 · 핵심 요약 · **목차(자동 추출)** · 키워드 · 연구 질문/가설 ·
**연구방법론**(설계/데이터/기법/절차 + 본문에서 탐지한 분석 기법) · 주요 결과 · 이론적/실무적 시사점 ·
**쟁점 · 비판적으로 읽기** · **한계점** · 후속 연구 아이디어 · **내 연구와의 연결** ·
관련 개념 + 함께 읽을 논문(OpenAlex) · 세미나 토론 질문 · 용어 정리

리포트는 `data/reports/`에 저장됩니다.

## AI 엔진 (설정에서 선택)

| 엔진 | 비용 | 속도 | 특징 |
|---|---|---|---|
| **Ollama** (기본, `qwen3:8b`) | 무료 | GPU 없으면 논문 1편에 약 10분 | 논문이 PC 밖으로 나가지 않음, 오프라인 |
| **Gemini API** 무료 티어 | 무료 | 수십 초 | https://aistudio.google.com/apikey 에서 키 발급 후 설정에 입력. 본문이 Google로 전송됨 |
| **Claude Code CLI** | 내 Claude 구독 한도 내 | 1~2분 | 분석 품질이 가장 좋음. `claude` 명령이 설치돼 있으면 사용 가능 |
| 규칙 기반 | 무료 | 즉시 | LLM 없이 원문 문장 발췌 + 방법론 사전 매칭 (안전망) |

`자동`으로 두면 Ollama → Gemini → Claude → 규칙 기반 순서로 사용할 수 있는 엔진을 고릅니다.
더 빠른 로컬 모델이 필요하면 `ollama pull gemma3:4b`처럼 작은 모델을 받아 설정에서 바꿔 보세요.

## 폴더 구조

```
research-lab/
├─ app.py              # 웹 서버 (Flask) + 자동 수집 스케줄러
├─ collect.py          # 서버 없이 수집만 실행 (작업 스케줄러용)
├─ config.json         # 내 설정 (처음 실행할 때 생성, 화면에서 수정 가능)
├─ lab/
│  ├─ collectors.py    # 논문/뉴스/이슈/데이터 수집기
│  ├─ analyzer.py      # PDF 파싱·목차 추출·LLM/규칙 기반 분석·관련 논문
│  ├─ report_pdf.py    # 한글 PDF 리포트 생성
│  ├─ llm.py           # Ollama / Gemini / Claude CLI 엔진
│  ├─ jobs.py          # 수집·브리핑·분석 큐·스케줄러
│  └─ storage.py       # SQLite 저장소
├─ templates/, static/ # 대시보드 화면
└─ data/               # lab.db, uploads/, reports/, 로그
```

## 팁
- 영어 키워드는 **2~4단어의 구체적인 표현**이 잘 맞아요 (예: `online reviews text mining`).
- 학교 도서관을 통해서만 받을 수 있는 논문은 직접 내려받아 업로드하세요. 자동 다운로드는 arXiv와 오픈액세스 논문만 됩니다.
- 스캔 이미지로 된 PDF는 텍스트를 추출할 수 없어요.
